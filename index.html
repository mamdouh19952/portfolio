AI-assisted development

I build with Claude Code, and I keep it on a short leash

Specs before code

Full-stack projects start as a written spec with Spec Kit: user stories, a plan, then tasks. The specs/ folders in the horse and medical-equipment repos show the process.

Rules the agent follows

A CLAUDE.md in each repo fixes the API response shape, folder layout and conventions, so the code from task forty matches the code from task one.

Skills I maintain

Two public skill sets for Claude Code: Laravel and PHP conventions and a Spec Kit workflow.

I read, run and test everything the agent writes. The architecture and the trade-offs are mine.
